# Документация проекта IT Job Tracker

Черно-белая версия для печати.  
Дисциплина: React + Redux.  
Формат: индивидуальный проект.  
Проект: IT Job Tracker, трекер вакансий для программистов на React, Redux Toolkit и REST API.

## Страница 1. Общая информация о проекте

IT Job Tracker является учебным одностраничным приложением, которое показывает полный поток работы с данными во frontend-проекте. Тематика проекта - учет вакансий для программиста. Пользователь может просматривать вакансии, искать подходящие позиции, применять фильтры, сохранять интересные варианты, менять статус отклика и вести заметки по каждому процессу найма.

Основные возможности приложения:

1. Dashboard - обзор количества вакансий, сохраненных позиций, активных откликов и интервью.
2. Jobs - список вакансий, поиск, фильтры, сохранение, изменение статуса и удаление.
3. Create - форма добавления новой вакансии.
4. Edit - редактирование вакансии и CRUD заметок.
5. Saved - отдельный список сохраненных вакансий.
6. Companies - список компаний и рекрутеров.
7. Docs - краткое описание архитектуры внутри приложения.

Внешний источник данных - JSONPlaceholder. Для учебной темы трекера вакансий данные endpoint `/posts` нормализуются в вакансии, а endpoint `/users` нормализуется в компании. API поддерживает демонстрационные POST, PUT и DELETE запросы. JSONPlaceholder не сохраняет изменения на сервере навсегда, поэтому приложение после успешных операций обновляет Redux state локально. Такое поведение подходит для демонстрации Redux Toolkit, createAsyncThunk и CRUD-потока.

Проект удовлетворяет ключевым требованиям:

- используется React;
- есть маршрутизация через React Router;
- используется Redux Toolkit;
- store настроен через `configureStore`;
- состояние разделено на slice-файлы;
- данные читаются через `useSelector`;
- действия запускаются через `useDispatch`;
- асинхронная логика реализована через `createAsyncThunk`;
- есть работа с REST API;
- реализованы GET, POST, PUT и DELETE операции;
- есть CRUD вакансий;
- есть CRUD заметок;
- есть поиск и фильтрация;
- есть сохраненные вакансии;
- есть статусы откликов;
- отображаются loading, error и empty состояния.

## Страница 2. Структура проекта и маршрутизация

Главная структура находится в папке `src`.

```text
src/
  components/
    JobCard.js
    JobFilters.js
    JobForm.js
    NotesManager.js
  hooks/
  pages/
    DashboardPage.js
    JobsPage.js
    CreateJobPage.js
    EditJobPage.js
    SavedJobsPage.js
    CompaniesPage.js
  redux/
    store.js
    slices/
      jobsSlice.js
      companiesSlice.js
  routes/
    AppRoutes.js
  services/
    apiClient.js
    jobsApi.js
    companiesApi.js
  utils/
    jobs.js
    companies.js
  App.js
```

Папка `components` содержит переиспользуемые части интерфейса. `JobCard` отображает вакансию, `JobFilters` содержит фильтры, `JobForm` используется для создания и редактирования вакансии, `NotesManager` отвечает за CRUD заметок, `StateBox` показывает loading/error/empty состояния.

Папка `pages` содержит экраны приложения. `JobsPage` показывает список вакансий, `CreateJobPage` открывает форму создания, `EditJobPage` открывает форму редактирования и заметки, `SavedJobsPage` показывает сохраненные вакансии, `CompaniesPage` показывает компании, а `DashboardPage` выводит метрики.

Маршрутизация описана в `src/routes/AppRoutes.js`:

- `/` - обзор проекта;
- `/jobs` - список вакансий;
- `/jobs/new` - создание вакансии;
- `/jobs/:jobId/edit` - редактирование вакансии и заметок;
- `/saved` - сохраненные вакансии;
- `/companies` - компании;
- `/documentation` - справка;
- `*` - страница 404.

## Страница 3. Redux Toolkit и состояние

Store создается в `src/redux/store.js`:

```js
export const store = configureStore({
  reducer: {
    companies: companiesReducer,
    jobs: jobsReducer,
  },
});
```

В проекте два основных slice:

1. `jobsSlice` - вакансии, фильтры, сохраненные, статусы откликов, CRUD вакансий и CRUD заметок.
2. `companiesSlice` - компании, рекрутеры, загрузка и ошибки.

Состояние `jobsSlice` содержит:

- `items` - массив вакансий;
- `loading` - состояние загрузки;
- `loaded` - признак первой загрузки;
- `submitting` - состояние сохранения формы;
- `deletingIds` - id удаляемых вакансий;
- `error` - текст ошибки;
- `filters` - поиск, компания, статус, формат и признак saved;
- `lastSync` - время последней загрузки.

Фильтры хранятся в Redux, поэтому выбранный поиск и параметры фильтрации являются частью общей модели приложения. Селектор `selectFilteredJobs` пересчитывает список вакансий по поиску, компании, статусу, формату и сохраненным.

Сохранение вакансии выполняется action `toggleJobSaved`. Изменение статуса отклика выполняется action `setJobStatus`. Заметки управляются actions `addJobNote`, `updateJobNote` и `deleteJobNote`.

## Страница 4. REST API и асинхронные операции

Асинхронная логика реализована через `createAsyncThunk`. Это позволяет разделить UI, Redux state и HTTP-запросы.

Основные операции:

- `fetchJobs` - GET `/posts`, загрузка и нормализация вакансий;
- `createJob` - POST `/posts`, создание вакансии;
- `updateJob` - PUT `/posts/:id`, обновление вакансии;
- `deleteJob` - DELETE `/posts/:id`, удаление вакансии;
- `fetchCompanies` - GET `/users`, загрузка компаний.

Слой API расположен в папке `src/services`. `apiClient.js` содержит общий helper `apiRequest`, который добавляет базовый URL, заголовки, обработку ошибок и парсинг JSON. `jobsApi.js` содержит методы для вакансий, а `companiesApi.js` - метод загрузки компаний.

Поток загрузки выглядит так:

1. Страница вызывает `useInitialData`.
2. Hook проверяет, загружались ли вакансии и компании.
3. Если данных еще нет, dispatch запускает `fetchJobs` и `fetchCompanies`.
4. Thunk вызывает сервис API.
5. Полученные данные нормализуются в доменную модель IT Job Tracker.
6. Redux state обновляется, UI автоматически перерисовывается.

Loading, error и empty состояния выводятся на страницах обзора, списка вакансий, создания, редактирования и компаний.

## Страница 5. Пользовательские сценарии

Сценарий просмотра вакансий: пользователь открывает `/jobs`, видит список карточек, компанию, стек, формат работы, зарплату, статус отклика и количество заметок. Поиск работает по названию, стеку, описанию и локации.

Сценарий фильтрации: пользователь выбирает компанию, статус отклика, формат работы или включает "Только сохраненные". Фильтры находятся в Redux state и применяются через memoized selector.

Сценарий сохранения: пользователь нажимает "Сохранить" на карточке вакансии. Action меняет поле `saved`. Вакансия появляется на странице `/saved`.

Сценарий статуса отклика: пользователь меняет select "Статус отклика" прямо в карточке. Возможные статусы: в планах, отклик отправлен, скрининг, интервью, оффер, отказ.

Сценарий CRUD вакансии:

- Create: форма на `/jobs/new` собирает компанию, название, стек, описание, формат, зарплату и статус.
- Read: вакансии загружаются через GET и отображаются на Dashboard, Jobs и Saved.
- Update: страница `/jobs/:jobId/edit` изменяет данные вакансии.
- Delete: кнопка удаления удаляет вакансию из Redux state.

Сценарий CRUD заметок:

- Create: пользователь добавляет заметку на странице редактирования вакансии.
- Read: заметки отображаются под формой вакансии.
- Update: пользователь редактирует текст заметки.
- Delete: пользователь удаляет ненужную заметку.

Проект сохраняет учебную архитектуру React + Redux Toolkit, но полностью переведен в предметную область IT Job Tracker.
